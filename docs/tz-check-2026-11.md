# Сверка исторических часовых поясов, ноябрь 2026

Начата 9 ноября 2026 после второй проверки кода (`docs/review-2026-11-09.md`, находки #6 и #7). Метод выбран через `/be-ambitious`: источники независимы, сравнение вслепую, расхождения разбираются по закону, а не большинством.

## Источники

1. **Astrovarium** (node-стенд из index.html).
2. **IANA tzdata 2026c с backzone**, собранная zic и прочитанная Python zoneinfo, то есть другой реализацией.
3. **ACS через Astro Gold** (вводит Дафа).
4. **ACS через astro.com** (ждёт решения: сайт требует принять свою политику данных, а у атласа запрет на систематическое извлечение).

## Шаг 1: Astrovarium против IANA, весь набор

Набор построен программой: каждый переход в 394 поясах атласа с 1800 по 1980 год, по четыре пробы на переход (за сутки, за час, через час, через сутки). Всего **30 068 случаев**.

- **3.22.2 до исправления** (0dd7eb1): 1197 расхождений в 95 поясах, все до 1970 года. Это пояса-ссылки без backzone (находка #6).
- **после исправления** (16c6598): **0 расхождений**.

Стенд сравнивает смещение пояса. Слой «по месту рождения» (местное среднее время до конца LMT, правило городов Российской империи) проверяется шагом 2, потому что IANA на него не отвечает: база знает время опорного города, а не каждой деревни.

Оговорка: node использует ICU с базой 2026a. Браузеры несут свои копии, а Safari на iPhone берёт системную; после 1970 года Astrovarium читает именно её. Сверка в Safari ещё впереди.
